# Sales Trend Analysis Dashboard

## Project Overview
This project focuses on analyzing sales performance using Power BI. It provides interactive visualizations to understand sales trends, profitability, order distribution, and customer segments.

## Tools Used
- Microsoft Power BI
- Data Cleaning and Data Visualization

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Sales Trend by Year
- Profit by Product Category
- Orders by Payment Method
- Orders by Region
- Sales by Customer Segment
- Sales by Product Name
- Interactive Year and Region Slicers
